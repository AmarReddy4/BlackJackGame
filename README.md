# Blackjack Game

A simple browser-based Blackjack card game built with vanilla JavaScript.

## How It Works

- Click **START GAME** to receive two random cards
- Click **NEW CARD** to draw additional cards
- Get as close to 21 as possible without going over
- Hit exactly 21 for Blackjack
- Player starts with $200 in chips

## Tech Stack

- HTML, CSS, JavaScript

## How to Run

Open `Blackjack/index.html` in any web browser.
